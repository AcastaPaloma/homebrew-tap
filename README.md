# AcastaPaloma Tap

## How do I install these formulae?

`brew install acastapaloma/tap/<formula>`

Or `brew tap acastapaloma/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "acastapaloma/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
